# Archimede rover
The github of the archimede rover developed at the Department of Engineering and Architecture of the University of Trieste.


## Installation
To clone this main repo with all the submodules, run:
```
git clone --recurse-submodules -b ros2_humble https://github.com/unitsSpaceLab/archimede_rover.git
```

## Python dependencies
Python dependencies for the submodules are listed in *pkgs_python_requirements.txt*.

The use of a python environment is recommended. Please refer to the [*kinematics package*](https://github.com/unitsSpaceLab/ros-rover4ws-kinematics/tree/ros2_humble) for the installation of the python environment and Archimede dependencies.
